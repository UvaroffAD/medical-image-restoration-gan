# Практическая программа по диссертации Уварова

Интерфейс оформлен под интеграцию в АК БАРС Медицина: русский язык, логотип, медицинская визуальная стилистика, отчеты с метриками восстановления и распознавания объектов.

## Что внутри архива

- `web_app.py` - локальный веб-интерфейс.
- `start_windows.bat` - быстрый запуск на Windows.
- `requirements.txt` - Python-зависимости.
- `uvarov_restoration/` - основной модуль обработки изображений.
- `models/` - уже обученные lightweight-модели для микроскопии и спектральной КТ.
- `assets/akbars_logo.svg` - логотип для интерфейса и отчетов.
- `runs/microscopy_demo/report.html` - готовый демо-отчет по микроскопии.
- `runs/ct_demo/report.html` - готовый демо-отчет по спектральной КТ.
- `run_demo.py` - CLI-запуск демо и обработка одного изображения.
- `train_prior.py` - переобучение локальной модели.
- `README.md` и `study_notes.md` - техническое описание и заметки по диссертации.

## Как запустить на Windows

1. Распаковать архив в любую папку, например на рабочий стол.
2. Установить Python 3.10 или новее, если он еще не установлен.
3. Открыть папку с программой.
4. Дважды нажать `start_windows.bat`.
5. После запуска открыть в браузере:

```text
http://127.0.0.1:8765/
```

Если окно пишет, что `python` или `py` не найден, нужно установить Python и поставить галочку `Add Python to PATH` при установке.

## Ручной запуск через PowerShell

Открыть PowerShell в папке программы и выполнить:

```powershell
python -m pip install -r requirements.txt
python web_app.py --host 127.0.0.1 --port 8765
```

После этого открыть:

```text
http://127.0.0.1:8765/
```

## Как пользоваться интерфейсом

1. В блоке `Медицинское изображение` выбрать PNG/JPEG или ничего не выбирать, чтобы программа создала демонстрационный пример.
2. В поле `Модальность` выбрать:
   - `Флуоресцентная микроскопия` - изображения с объектами и шумом/размытием.
   - `Спектральная КТ` - изображения с полосовыми артефактами и шумом.
3. В поле `Алгоритм восстановления` выбрать:
   - `Сравнить все методы` - программа построит полный отчет по всем алгоритмам.
   - `Обученная модель` - применит заранее обученный lightweight-prior.
   - `Фильтр Винера`, `Ричардсон-Люси`, `WF-hybrid`, `TRL-hybrid`, `CT-hybrid` - отдельные методы восстановления.
4. Нажать `Запустить обработку`.
5. Откроется HTML-отчет с изображениями, метриками и разметкой объектов.

## Что показывает отчет

- `PSNR` - насколько восстановленное изображение ближе к эталону по уровню ошибки.
- `SSIM` - структурное сходство изображения с эталоном.
- `IoU` - качество совпадения найденных объектов с эталонной маской.
- `Объекты` - сколько объектов найдено после восстановления.
- `Разметка` - ссылка на картинку с наложенной маской/детекцией.

Для пользовательского загруженного изображения эталона нет, поэтому часть метрик может быть пустой или считаться только по доступным данным.

## Быстрые демо без загрузки файла

В интерфейсе есть кнопки:

- `Демо: микроскопия`
- `Демо: КТ`

Они сразу запускают обработку синтетического медицинского примера и открывают отчет.

## CLI-команды

Сгенерировать отчет по микроскопии:

```powershell
python run_demo.py --preset microscopy --out runs\microscopy_demo
```

Сгенерировать отчет по спектральной КТ:

```powershell
python run_demo.py --preset ct --out runs\ct_demo
```

Обработать свой файл:

```powershell
python run_demo.py --input path\to\image.png --preset microscopy --out runs\my_case
```

Переобучить lightweight-модели:

```powershell
python train_prior.py --samples 72 --size 192 --out models
```

## Как это связано с диссертацией

В диссертации рассматривается повышение качества распознавания объектов на изображениях через предварительное восстановление изображения. В программе реализован практический контур:

1. Генерация или загрузка изображения.
2. Искажение/наличие шума, размытия или полосовых артефактов.
3. Восстановление классическими и гибридными методами.
4. Применение обученного lightweight-prior.
5. Downstream-оценка: сегментация/детекция объектов и расчет метрик.
6. Формирование наглядного HTML-отчета.

Это готовый MVP для демонстрации практической части. Тяжелая GAN-модель здесь заменена легкой обучаемой моделью, чтобы программу можно было передать и запустить без GPU и сложной установки.

## Если что-то не запускается

- Если порт занят, запустить на другом порту:

```powershell
python web_app.py --host 127.0.0.1 --port 8766
```

И открыть `http://127.0.0.1:8766/`.

- Если не ставятся зависимости, вручную выполнить:

```powershell
python -m pip install numpy Pillow
```

- Если в отчете не видно логотип, убедиться, что папка `assets` лежит рядом с `web_app.py`.

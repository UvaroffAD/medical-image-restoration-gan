# Uvarov Medical Image Restoration MVP

Практическая реализация по диссертации Уварова А.Д.:
"Применение генеративно-состязательных нейронных сетей для повышения качества распознавания объектов на изображении".

Это MVP, который запускается без установки тяжелых зависимостей. Достаточно Python 3.10+ и библиотек из `requirements.txt`. Проект реализует:

- синтез тестовых микроскопических и CT-like изображений;
- деградацию изображений: PSF blur, пуассоновский шум, гауссовский шум, полосовые артефакты;
- классические методы восстановления: Richardson-Lucy, Wiener;
- гибридные физически-информированные proxy-методы:
  - `trl_hybrid`: RL-развертка + регуляризатор высокочастотных деталей;
  - `wf_hybrid`: Wiener + пространственно-адаптивная регуляризация;
  - `ct_hybrid`: подавление полос + контрастное восстановление;
- обученный lightweight prior `trained_prior`, веса лежат в `models/*.npz`;
- простую downstream-оценку: сегментация объектов, bounding boxes, IoU/mAP-like proxy;
- метрики восстановления: MSE, PSNR, SSIM;
- CLI-демо и локальный web-интерфейс.

Важно: текущая версия не притворяется обученной GAN-моделью. В ней есть архитектурный слот `PriorRegularizer`, куда позже подключаются PyTorch-веса TRL-GAN/WF-GAN/AGC-GAN.

## Обучение локальной модели

```powershell
python train_prior.py --samples 72 --size 192 --out models
```

После обучения web-интерфейс и CLI автоматически используют метод `trained_prior`.

## Быстрый запуск

Сгенерировать демо-отчет:

```powershell
python run_demo.py --preset microscopy --out runs\microscopy_demo
```

Запустить web-интерфейс:

```powershell
python -m pip install -r requirements.txt
python web_app.py --host 127.0.0.1 --port 8765
```

Потом открыть:

```text
http://127.0.0.1:8765
```

## Где развивать до настоящей диссертационной реализации

Следующий слой после MVP:

1. Добавить PyTorch.
2. Реализовать `TorchPriorRegularizer`.
3. Подключить обученные веса TRL-GAN/WF-GAN/AGC-GAN.
4. Заменить proxy downstream-детектор на YOLO/nnU-Net или другой детектор из экспериментов.
5. Добавить загрузку реальных датасетов и скрипты обучения.
